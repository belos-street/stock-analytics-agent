# Agent 口径与红线（模式 2 运行时精简版）

> 本文件是模式 2 的读取白名单之一（D21），只沉淀口径与红线，不写工程决策。
> 另：`watchlist/` 下的 md/html 可经 `read_watchlist` 只读（D22），不得扩展到其他目录。
> 与 `.agents/memory/decisions.md` 的 D9-D11 对齐；口径冲突时以本文件为准。

## 1. 估值分位

- 口径：近 10 年、月频、PE-TTM、整体法（成分股合计市值 / 合计盈利），剔除负 PE。
- 输出必须同时给出：指标（PE / PB）、窗口（近 10 年）、数据基准日。
- 拿不到历史 PE 序列时，只给“当前 PE/PB + 价格分位”，并明确说明“无历史估值分位”；价格分位不得表述为估值分位。

## 2. 股息率

- 以工具返回的 `yield_basis` 为准，并原样说明口径；当前工具是“单期已实施分红 / 现价”，不是年度化。
- 如需年度化，必须明确标注为估算（如单期 × 4 粗略年化），不得当作工具默认口径。
- 不同分红频次的标的不可直接横向比较。

## 3. 回撤 / 年内高低

- 一律用 monthly 完整周期，不用局部窗口冒充“年内 / 近一年”。
- 说明起止日期与 bar 数；当月未完结时注明“当月未完结”。
- 回撤为区间收盘价峰谷，负值表示回撤。

## 4. 仓位约束

- 单只个股 ≤ 10%；单只高风险 / 行业 ETF ≤ 5%。
- 避免同风格重复暴露（如多只红利 ETF、多只半导体 ETF）。
- 先提示占比漂移（drift），再给再平衡动作；不直接下买卖指令。

## 5. 价格位

- 价格位必须注明性质：持有参考位 / 观察位 / 减仓位，不是买卖指令。
- 禁止“精确买卖点”“必涨 / 必跌”“稳赚”等表述。

## 6. 红线

- 不承诺收益、不预测概率、不保本、不给精确买卖点。
- 所有分析结尾标注“仅供参考，不构成投资建议；市场有风险，投资需谨慎”。
