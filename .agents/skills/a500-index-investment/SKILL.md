### 目标用户
- **宽基指数投资者**：将A500作为底仓配置的投资者
- **定投/网格投资者**：采用分批建仓策略的投资者
- **资产配置者**：将A500作为权益底仓的投资者

### 技能边界

**可提供服务**：
- A500指数估值状态判断（PE分位数、当前点位相对建仓点的位置）
- 精确建仓时机建议（基于PE阈值）

- 具体某一天的买卖指令
- 保证收益

## 📥 建仓规则（严格纪律）

### ⛔ 禁止建仓区：PE > 17.0x（当前在此区间）

> **当前 PE ~18.0x，处于 98% 分位。绝对禁止建仓。等 PE 回落到 15.5x 以下再考虑。**

**为何禁止**：
- 历史上在此位置买入，未来1-3年回报率极低甚至为负
- 安全边际为零，任何利空都可能导致大幅回撤
- 资金效率极低，倒金字塔无法展开

### 🟡 观望区：PE 15.5x - 17.0x

- **不建仓，不卖出**，持有现金等待
- 如果已持仓，继续持有不操作

点位随EPS增长自然上移，**每季度检查一次**：

### 估值速查卡

计算当前PE对应的操作：

```
PE = 当前点位 / 预期EPS
预期EPS ≈ 当前点位 / 当前PE

估算公式（快速判断）：
- PE > 17.0x → 高估，禁止建仓
```

## 🐻 空方论点 / 看空情景 / 证伪条件（输出必填）

凡输出分析/报告/结论/建议，**必须**包含以下三段，不得以单行"风险提示"替代，也不得只写多头结论：

**空方论点（必填，与多头结论并列呈现）**：
- **估值已处高位**：当前 PE ~18.0x（98% 分位），安全边际为零；"越跌越买"的倒金字塔在 EPS 下修时会被动失真（低 PE ≠ 便宜）
- **EPS 增速假设可能落空**：历史 EPS 增速约 8-10%/年、长期年化约 10% 均为历史经验（作者假设，非承诺）；若盈利增速下修，各档点位锚须同步下移（见"点位动态调整规则"对称规则），原锚不再是"低估"
- **盈利顶部陷阱**：宏观下行期 EPS 下修速度快于价格下跌，PE 被动抬升或"回落"都可能是周期顶部假象
- **风格/结构风险**：A500 与沪深300 等宽基底层持仓部分重叠，分散是"个股分散"而非"风险因子分散"；单一宏观冲击（地产/出口/信用）仍同向传导

**看空情景（可证伪）**：
- 情景 A：盈利下修 + 估值收缩"双杀"，PE 回落到 15.5x 但 EPS 同步下修，实际并不便宜，倒金字塔被动摊低失败
- 情景 B：宏观冲击（地产/出口/信用）导致指数盈利增速降至 0 附近，"长期年化~10%"的持有逻辑失效
- 情景 C：市场风格转向窄基/主题，宽基长期跑输，机会成本高企

**证伪条件 / 观察指标（触发即结论失效、须重估）**：

| 观察指标 | 证伪方向 |
|:--|:--|
| A500 EPS / 盈利预期（口径+基准日） | 下修 → 各档 PE/点位锚同步下移，原建仓线失效 |
| PE 与 EPS 联动 | PE 回落但 EPS 同步下滑（"假便宜"） |
| 宏观传导（地产/出口/信用） | 恶化至影响指数整体盈利 |
| 相对收益 | 持续大幅跑输同类宽基，分散价值证伪 |

### 估值陷阱检查项（必填）

凡结论涉及"低估/便宜/可以建仓"，必须逐项核查并写明结论：
- **低 PE ≠ 便宜**：警惕盈利顶部（周期股陷阱）——须同时核对 EPS 趋势，PE 回落若由 EPS 下修造成则为假信号
- **回撤大 ≠ 估值低**：区分"杀估值"与"杀逻辑/杀业绩"，跌幅本身不构成低估证据
- **高股息可持续性**：核对分红率、自由现金流覆盖、分红政策，警惕分红率下调（`yield_basis` 同口径）
- **增长质量**：盈利含量（是否依赖非经常性损益）与现金含量（收现比/净现比），决定 EPS 锚是否可信

## ⚠️ 风险提示

1. **PE不是唯一指标**：极端情况下（如盈利崩塌），PE可能被动升高，需结合宏观经济判断
2. **点位计算是近似值**：实际点位受EPS变动影响，每季度需重新校准
3. **倒金字塔需要纪律**：最难的不是在底部买，而是在底部敢买。提前做好心理建设
4. **长期主义是前提**：本策略基于10年以上持有周期，短期波动不可避免
