# 信用分析

## 技能核心定位

### 核心目标
系统化信用研究能力，覆盖主体信用、行业风险、财务健康度、现金流质量、评级对标、违约概率建模，为债券投资和风险管理提供定量依据。集成风险评分系统，提供更精准的违约概率评估。

### 目标用户
- **债券投资者**：评估发行人信用资质
- **信用风险管理**：识别高风险主体
- **投资组合构建**：筛选符合风险偏好的标的
- **研究分析师**：进行信用评级验证
- **风控人员**：评估违约概率

### 技能边界

**可提供服务**：
- 主体信用资质分析
- 行业风险评估
- 财务健康度诊断
- 现金流质量分析
- 内部评级构建
- 违约概率建模

**不可提供服务**：
- 投资建议
- 承诺收益
- 确定性违约判定、基于违约预测的买卖建议
- 内幕信息

> 说明：违约概率（PD）输出为**模型估算区间**，须标注评估方法/参数/数据基准日，属信用风险量化参考，非精确预测，不得直接转为买卖指令。

## 信用分析框架

### 一、主体资质分析

#### 基本面评估
```
1. 企业性质
   - 国企/民企/央企
   - 股东背景
   - 行政层级

2. 行业地位
   - 市场份额
   - 竞争壁垒
   - 盈利能力

3. 公司治理
   - 管理层稳定性
   - 股权结构
   - 激励约束机制

4. 业务模式
   - 收入结构
   - 盈利模式
   - 抗周期能力
```

#### 经营能力评估
```
指标体系：
- 营收规模与增速
- 盈利能力（毛利率、净利率）
- 运营效率（存货周转、应收账款周转）
- 成长性（营收增速、利润增速）
```

### 二、行业风险分析

#### 行业特性评估
```
1. 行业周期
   - 强周期/弱周期
   - 周期阶段

2. 政策环境
   - 支持政策
   - 限制政策
   - 监管趋势

3. 竞争格局
   - 行业集中度
   - 波特五力分析
   - 竞争壁垒

4. 行业趋势
   - 市场规模增长
   - 技术变革
   - 替代品威胁
```

#### 行业信用风险矩阵
| 行业 | 信用风险 | 典型行业 |
|------|---------|---------|
| 低风险 | 城投、电力、银行 | 稳定现金流 |
| 中低风险 | 医药、消费 | 需求稳定 |
| 中风险 | 化工、制造业 | 周期波动 |
| 中高风险 | 房地产、贸易 | 高杠杆 |
| 高风险 | 航空、养殖 | 亏损严重 |

### 三、财务健康度诊断

> **校准注释**：以下各财务指标不设全市场统一绝对阈值（固定百分比一刀切），一律对照**同业/自身**历史区间（标注窗口+算法+基准年份）；不同行业杠杆与盈利结构天然不同（如地产与医药），阈值调整须记录原因。

#### 盈利能力
```
核心指标：
- 毛利率：对照同业/自身历史区间（标注窗口+基准年份）
- 净利率：对照同业/自身历史区间（标注窗口+基准年份）
- ROE：对照同业/自身历史区间（标注窗口+基准年份）
- 营收增速：与行业对比

评估方法：
- 趋势分析（3-5年）
- 同业对比
- 异常波动识别
```

#### 偿债能力
```
短期偿债：
- 流动比率：对照同业/自身历史区间（标注窗口+基准年份）
- 速动比率：对照同业/自身历史区间（标注窗口+基准年份）
- 现金比率：对照同业/自身历史区间（标注窗口+基准年份）

长期偿债：
- 资产负债率：对照同业/自身历史区间（不同行业杠杆天然不同，标注基准年份）
- 产权比率：对照同业/自身历史区间（标注基准年份）
- 利息保障倍数：对照同业/自身历史区间（标注窗口+基准年份）

刚性压力：
- 短期有息负债
- 一年内到期债券
- 外部担保
```

#### 资产质量
```
应收账款：
- 账龄分析
- 坏账准备
- 集中度风险

存货：
- 存货周转天数
- 跌价准备
- 变现能力

商誉：
- 商誉/净资产：对照同业/自身历史区间（标注基准年份），占比显著抬升需警惕
- 商誉减值风险

受限资产：
- 资产抵押情况
- 受限比例
```

### 四、现金流质量分析

#### 现金流结构
```
经营现金流（核心）：
- 净现比：对照同业中位/自身历史区间（标注窗口+基准年份）
- 经营现金流/EBITDA：对照同业/自身历史区间（标注窗口+基准年份）
- 趋势分析

投资现金流：
- 资本开支合理性
- 在建工程进度
- 并购扩张节奏

筹资现金流：
- 融资渠道畅通度
- 再融资压力
- 债务到期分布
```

#### 现金流分析矩阵
| 类型 | 经营 | 投资 | 筹资 | 评价 |
|------|------|------|------|------|
| 优质型 | + | - | - | 自我造血 |
| 稳健型 | + | - | + | 扩张期 |
| 维持型 | + | + | + | 依赖融资 |
| 恶化型 | - | +/- | + | 危险信号 |

### 五、评级对标分析

#### 外部评级参考
```
评级符号：
- AAA：最高信用
- AA+、AA、AA-：高信用
- A+、A、A-：中上信用
- BBB+、BBB：中等信用
- BB+及以下：投机级

评级机构：
- 中诚信
- 联合评级
- 东方金诚
- 标普、穆迪（美元债）
```

#### 内部评级构建
```
评级维度：
1. 主体资质（40%）
2. 财务状况（30%）
3. 行业风险（20%）
4. 支持因素（10%）

评级结果：
- 1-3级：优质
- 4-6级：良好
- 7-8级：一般
- 9-10级：关注/违约
```

### 六、违约概率建模

#### 关键预警指标
```
财务预警：
- 连续2年亏损
- 经营现金流持续为负
- 货币资金/短期有息负债 显著低于同业/自身历史区间（标注基准年份）
- 授信银行减少
- 拖欠工资

事件预警：
- 评级下调
- 重大诉讼
- 高管变动
- 关联交易异常
- 会计政策变更

市场预警：
- 债券价格异动
- 信用利差走扩
- 成交价格异常
```

#### 违约概率评估
```
评估方法：
1. 定性分析（专家判断）
2. 定量模型（Z-score、KMV）
3. 市场隐含（信用利差）

违约概率等级（模型输出标度，须标注评估方法/参数/数据基准日；分档随样本与方法校准，非固定刻度）：
- <1%：极低
- 1-3%：低
- 3-10%：中等
- 10-20%：较高
- >20%：高
```

## 使用示例

### 示例1：信用资质分析
**用户**："帮我分析一下宁德时代的信用资质"
**Agent**：
1. 分析主体资质和行业地位
2. 评估财务健康度
3. 分析现金流质量
4. 给出内部评级

### 示例2：违约概率评估
**用户**："XX房地产公司的违约概率是多少？"
**Agent**：
1. 分析房地产行业风险
2. 评估公司财务状况
3. 构建违约概率模型
4. 给出风险提示

### 示例3：信用风险对比
**用户**："对比分析万科和保利的信用风险"
**Agent**：
1. 对比两家公司的财务指标
2. 分析现金流差异
3. 评估行业风险
4. 给出对比结论

### 示例4：财务健康诊断
**用户**："评估一下中国石化的财务健康度"
**Agent**：
1. 分析盈利能力
2. 评估偿债能力
3. 诊断现金流
4. 给出综合评价

## 重要提醒

1. **合规性**：所有分析仅供参考，不构成投资建议
2. **风险提示**：信用分析有固有局限性
3. **动态评估**：信用状况是动态变化的
4. **综合判断**：结合多方面信息
5. **定期跟踪**：定期复盘信用变化

## 数据获取与口径

- **获取方式**：优先本地 CLI `bun run main.ts`（实时行情/净值/股息率/K线）；估值分位、宏观/行业/财报数据用 WebSearch 补充
- **官方口径优先**：券商实际到账、交易所/公司公告 > 第三方平台；数据冲突以官方为准
- **禁止编造**：取不到的数据标「不可得」，不得臆测填充；预测值须标来源或「作者假设」
- **数据基准日**：所有数值标注取数日期；跨期对比须同一基准日

数据来源清单：

- 公司财报
- 评级机构报告
- 交易所公告
- 行业数据
- 公开市场信息
