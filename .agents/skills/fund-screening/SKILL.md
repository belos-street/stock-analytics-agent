# 基金筛选与投资建议

## 技能核心定位

### 核心目标
为投资顾问生成专业的基金筛选、对比分析和个性化投资建议。支持根据风险偏好、投资目标、投资期限等多维度筛选基金，对比业绩、风险、持仓、基金经理等指标，生成结构化分析报告，提供配置建议和投资者画像匹配。

### 目标用户
- **新手投资者**：选择首只基金，不知如何下手
- **有经验投资者**：优化基金组合，寻找替代标的
- **主题投资者**：特定行业主题投资需求
- **风险规避者**：市场不确定性期间寻找稳健标的

### 技能边界

**可提供服务**：
- 多维度基金筛选（风险偏好、收益目标、期限）
- 基金业绩与风险指标分析
- 基金经理能力评估
- 基金持仓结构分析
- 投资者画像匹配
- 基金组合配置建议

**不可提供服务**：
- 具体买卖指令
- 承诺收益
- 预测基金净值
- 内幕信息

**输出口径（S6）**：所有结论统一为「预期差方向 + 正反双方论点 + 配置参考」，不使用收益承诺、概率承诺或买卖指令式措辞；推荐/配置比例均为触发条件下的**配置参考**。

## 筛选维度

### 1. 风险偏好匹配

| 风险偏好 | 基金类型 | 配置比例建议 |
|---------|---------|-------------|
| 保守型 | 货币基金、纯债基金 | 固收100% |
| 稳健型 | 债券基金、混合债基、宽基ETF | 固收70%+权益30% |
| 平衡型 | 混合基金、宽基指数基金 | 固收50%+权益50% |
| 积极型 | 股票基金、行业主题基金 | 权益70%+固收30% |
| 激进型 | 行业主题基金、成长股基金 | 权益100% |

> **仓位口径**：单只个股 ≤ 总资金 10%；单只高风险/行业 ETF ≤ 总资金 5%（hard constraint）；高弹性组合避免同一成长风格重复暴露。三者是**不同层级约束**（个股上限 / 高风险ETF上限 / 组合风格去重），非同一口径，须分别校验。上表为**大类比例**参考（作者假设，按风险偏好分档），单只标的仍受上述硬约束。

### 2. 投资期限匹配

| 期限 | 风险承受建议 | 基金类型 |
|------|-------------|---------|
| 1年以内 | 低风险 | 货币基金、短债基金 |
| 1-3年 | 中低风险 | 纯债基金、混合债基 |
| 3-5年 | 中等风险 | 宽基指数、平衡混合 |
| 5年以上 | 中高风险 | 股票基金、行业主题 |

### 3. 收益目标匹配

> 📐 **口径注释**：下表"年化收益区间"为投资者主观**收益目标设定**（作者假设/用户设定，非收益承诺、非预测值），使用时须结合标的自身历史可得回报校准并标注数据基准日。

| 收益目标 | 年化收益区间 | 基金类型 |
|---------|-------------|---------|
| 低波动/现金管理 | 2-3% | 货币基金 |
| 稳健增值 | 4-8% | 纯债基金、混合债基 |
| 均衡收益 | 8-12% | 宽基指数、平衡混合 |
| 较高收益 | 12-20% | 行业主题、成长股基 |
| 高收益 | 20%+ | 激进成长、行业集中 |

## 筛选指标体系

### 业绩指标
- 年化收益率（近1/3/5年）
- 累计收益率
- 相对业绩基准的超额收益
- 排名百分位

### 风险指标
- 最大回撤
- 年化波动率
- 夏普比率
- 卡玛比率
- 下行标准差

### 风险调整收益
- 夏普比率、卡玛比率对照**同类基金**自身历史分布/分位判断优劣（标注窗口+算法+数据基准日），不设跨类型统一的"优秀线"
- 最大回撤 = 自区间高点起算的最大跌幅（标注起算点+统计窗口）；稳健与否按基金类型**分档**校准（货币/纯债/混合/股基各不同），不设跨类型统一阈值

### 基金规模
- 规模太小心得流动性风险
- 规模太大难以灵活配置
- 规模合理区间按基金类型**分档**校准（货币/纯债/指增/主动股基各不同），并结合策略容量与自身资金体量设定，须注明设定依据

### 基金经理
- 从业年限
- 管理期间业绩
- 风格稳定性
- 离职率

## 筛选流程

### 第一步：确定筛选条件
```
输入示例：
- 风险偏好：平衡型
- 投资期限：3年
- 收益目标：年化8-12%
- 可承受最大回撤：20%
```

### 第二步：执行筛选
```
筛选条件组合：
- 基金类型：混合型、股票型
- 近3年年化收益 > 10%
- 最大回撤 < 20%
- 基金规模 > 2亿
- 基金经理从业 > 3年
```

> 📐 **口径注释**：以上为基于上方输入示例的**示例条件**，其中收益/回撤/规模阈值不作为跨类型通用值——实际筛选时须按基金类型**分档**并对照标的自身/同类历史（回撤=自区间高点起算，标注起算点+窗口；业绩窗口与数据基准日须标注）。

### 第三步：业绩归因
- 分析收益来源：Alpha、贝塔、行业配置、个股选择
- 识别超额收益来源
- 评估收益可持续性

### 第四步：风险评估
- 分析回撤控制能力
- 评估波动率特征
- 压力测试

### 第五步：给出建议
- 推荐优先级排序
- 配置建议（含空方论点/证伪条件，见报告模板必填段）
- 配置参考与观察指标（「预期差方向 + 正反双方论点 + 配置参考」，不输出买卖指令）

## 投资者画像匹配

### 画像维度

**保守型投资者**：
- 无法承受本金亏损
- 投资期限短（1-3年）
- 收益预期：跑赢通胀即可
- 建议配置：货币基金+纯债基金

**稳健型投资者**：
- 可承受5-10%短期亏损
- 投资期限中等（3-5年）
- 收益预期：年化5-10%
- 建议配置：固收+宽基ETF

**平衡型投资者**：
- 可承受10-20%短期亏损
- 投资期限较长（5年以上）
- 收益预期：年化10-15%
- 建议配置：宽基+行业ETF

**积极型投资者**：
- 可承受20%+短期亏损
- 投资期限长（7年以上）
- 收益预期：年化15%+
- 建议配置：行业主题+成长股基

## 报告输出格式

### 基金筛选报告

```
# 基金筛选报告

## 投资者画像
- 风险偏好：
- 投资期限：
- 收益目标：
- 最大可承受回撤：

## 筛选条件
- 基金类型：
- 业绩要求：
- 风险要求：
- 规模要求：

## 筛选结果

### 核心推荐
| 基金代码 | 基金名称 | 风险等级 | 年化收益 | 最大回撤 | 推荐理由 | 不推荐/风险论点 |
|---------|---------|---------|---------|---------|---------|---------|
| 000001 | XX基金 | 中高 | 12% | 15% | 业绩稳健 | （必填：至少一条实质空方论据） |

### 备选标的
| 基金代码 | 基金名称 | 风险等级 | 年化收益 | 最大回撤 | 备注 | 不推荐/风险论点 |
|---------|---------|---------|---------|---------|-----|---------|
| 110011 | YY基金 | 高 | 15% | 22% | 弹性更大 | （必填） |

## 配置建议
- 核心配置（60%）：XX基金
- 卫星配置（30%）：YY基金
- 现金管理（10%）：货币基金

> **仓位口径**：单只个股 ≤ 总资金 10%；单只高风险/行业 ETF ≤ 总资金 5%（hard constraint）；高弹性组合避免同一成长风格重复暴露。三者是**不同层级约束**（个股上限 / 高风险ETF上限 / 组合风格去重），非同一口径，须分别校验。上表百分比为组合内部配比示例（作者假设），换算到总资金后仍须满足上述硬约束。

## 空方论点 / 看空情景 / 证伪条件（必填）
- **空方论点**：每只推荐标的至少一条实质论据（不得套话；不得只写"过往业绩不代表未来"）
- **看空情景**：可证伪的情景（触发条件 + 影响路径），覆盖盈利下修、风格反转、规模膨胀策略失效、基金经理变更等
- **证伪条件/观察指标**：列出可跟踪指标与方向（如业绩排名回落至同类后 1/2、回撤超出同类自身分位、风格漂移、基金经理变更），触发即推荐失效、须重估

## 估值陷阱检查项（必填）
- **低 PE ≠ 便宜**：警惕盈利顶部（周期股陷阱）——盈利处于周期高位时 PE 被动压低
- **回撤大 ≠ 估值低**：区分"杀估值"与"杀逻辑/杀业绩"，回撤幅度本身不构成低估证据
- **高股息可持续性**：核对分红率、自由现金流覆盖、分红政策，警惕分红率下调
- **增长质量**：盈利含量（是否依赖非经常性损益/杠杆）与现金含量（收现比/净现比）

## 风险提示
- 基金过往业绩不代表未来表现
- 请根据自身情况选择合适的基金
```

## 使用示例

### 示例1：新手投资者
**用户**："我是平衡型投资者，投资期限3年，帮我筛选几只合适的基金"
**Agent**：
1. 确定投资者画像：平衡型、3年、中等风险
2. 筛选混合型、宽基指数基金
3. 对比业绩、风险、基金经理
4. 给出3-5只推荐和配置建议

### 示例2：基金组合优化
**用户**："帮我分析这几只基金的风险收益特征：000001、110022、163406"
**Agent**：
1. 获取各基金历史数据
2. 计算风险收益指标
3. 进行同业对比
4. 给出优化建议

### 示例3：主题投资
**用户**："我想投资新能源主题基金，有什么推荐？"
**Agent**：
1. 筛选新能源主题基金
2. 对比各基金持仓（主动管理 vs 指数）
3. 分析新能源产业链分布
4. 给出推荐

### 示例4：稳健投资
**用户**："有没有适合养老的基金组合？"
**Agent**：
1. 确定养老投资特点：稳健、长期、分红
2. 筛选固收+、高股息基金
3. 构建稳健组合
4. 给出配置建议

## 重要提醒

1. **合规性**：所有分析仅供参考，不构成投资建议
2. **风险提示**：基金投资有风险，可能亏损
3. **长期视角**：基金适合长期投资，避免频繁申赎
4. **分散投资**：不要将所有资金投入单一基金
5. **定期检视**：定期评估基金表现，及时调整

## 数据获取与口径

- **获取方式**：优先本地 CLI `bun run main.ts`（实时行情/净值/股息率/K线）；估值分位、宏观/行业/财报数据用 WebSearch 补充
- **官方口径优先**：券商实际到账、交易所/公司公告 > 第三方平台；数据冲突以官方为准
- **禁止编造**：取不到的数据标「不可得」，不得臆测填充；预测值须标来源或「作者假设」
- **数据基准日**：所有数值标注取数日期；跨期对比须同一基准日
