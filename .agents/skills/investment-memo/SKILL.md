# 上市公司投资备忘录

## 技能核心定位

### 核心目标
帮你快速生成一份结构化的上市公司投资分析报告，涵盖公司业务与竞争力、投资逻辑、近期催化剂、财务与估值分析、风险提示和操作建议，适合晨会汇报、投决会准备或调研前快速了解一家公司。

### 目标用户
- **投资研究员**：快速生成研究报告
- **投资经理**：辅助投资决策
- **投决会成员**：了解标的情况
- **个人投资者**：深度研究个股

### 技能边界

**可提供服务**：
- 一页纸投资摘要
- 深度投资备忘录
- 晨会汇报材料
- 投决会演示材料
- 调研前准备材料

**不可提供服务**：
- 具体买卖指令
- 承诺收益
- 预测股价
- 内幕信息

### 估值陷阱检查（必填）
```
作出"估值合理/低估"结论前逐项核验：
- 低 PE = 盈利顶部（周期股陷阱）：MDI、化工、资源品等周期股在盈利顶部 PE 最低（如万华化学类标的须结合产品价格/产能周期位置判断），须用 PB 分位/产品价格分位交叉验证
- 回撤大 ≠ 估值低：股价大幅回撤后仍可能高估，对照自身历史估值分位，不以涨跌幅替代估值判断
- 概念/主题辨真伪：核验相关业务收入占比与商业化进度，警惕蹭热点
- 高股息可持续性：核验分红率与经营现金流对分红的覆盖，警惕一次性特别分红推高股息率
- 增长质量：核验增长来源（价/量/并表/政策）、现金流含量与可持续性，警惕低质量增长
```

## 重要提醒

1. **合规性**：所有分析仅供参考，不构成投资建议
2. **风险提示**：投资有风险，需要综合判断
3. **时效性**：定期更新，保持数据时效
4. **客观性**：客观呈现优劣势
5. **决策权**：投资决策权在投资者自己

---

## 数据获取与口径

- **获取方式**：优先本地 CLI `bun run main.ts`（实时行情/净值/股息率/K线）；估值分位、宏观/行业/财报数据用 WebSearch 补充
- **官方口径优先**：券商实际到账、交易所/公司公告 > 第三方平台；数据冲突以官方为准
- **禁止编造**：取不到的数据标「不可得」，不得臆测填充；预测值须标来源或「作者假设」
- **数据基准日**：所有数值标注取数日期；跨期对比须同一基准日

数据来源参考：公司公告、财报数据、行业研究、宏观数据。
