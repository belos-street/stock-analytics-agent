# 估值与定价框架

## 技能核心定位

### 核心目标
用于估值与定价框架，聚焦估值分析、定价逻辑、投资决策。帮助用户理解一家公司应该怎么估值、当前估值处于什么水平、市场为什么愿意给这个估值、还有没有重估空间。

### 目标用户
- **价值投资者**：关注估值高低，寻找低估标的
- **基本面研究者**：分析公司内在价值
- **投研分析师**：进行估值建模分析
- **投资决策者**：辅助买卖决策

### 技能边界

**可提供服务**：
- 相对估值法（PE、PB、PS、EV/EBITDA）
- 绝对估值法（DCF、DDM）
- 估值分位数分析
- 估值逻辑解读
- 同业对比分析
- 重估空间分析

**不可提供服务**：
- 具体买卖指令
- 承诺收益
- 预测股价
- 内幕信息

## 估值方法体系

### 1. 相对估值法

#### 市盈率（PE）
```
PE = 股价 / 每股收益
PE = 总市值 / 净利润
```

**适用场景**：
- 盈利稳定的成熟公司
- 同行业对比
- 周期行业需谨慎

**估值判断**：
| 分位数 | 估值水平 | 操作建议 |
|--------|---------|---------|
| < 20% | 历史低位 | 重点关注 |
| 20-50% | 偏低 | 可以配置 |
| 50-80% | 偏高 | 谨慎参与 |
| > 80% | 历史高位 | 回避 |

> 分位口径（S2 统一）：估值分位 = 该股**自身**近 10 年**月频**收盘（PE-TTM 整体法，负 PE 剔除）分位，标注数据基准日；上市不足 10 年按实际可得窗口并注明。上表为**对照自身历史**的参考分层，非买卖指令。

#### 市净率（PB）
```
PB = 股价 / 每股净资产
PB = 总市值 / 净资产
```

**适用场景**：
- 金融行业（银行、保险、券商）
- 制造业
- 资产重度公司

**估值判断**（阈值去硬编码，对照自身历史）：
| 分位数 | 估值水平 | 操作建议 |
|--------|---------|---------|
| < 20% | 历史低位 | 重点关注 |
| 20-50% | 偏低 | 可以配置 |
| 50-80% | 偏高 | 谨慎参与 |
| > 80% | 历史高位 | 需成长支撑 |

> 校准注释：不套用全市场统一绝对 PB 阈值（如 PB<1 破净即低估、PB>3 泡沫）；PB 分位 = 自身近 10 年月频收盘 PB 分位（标注数据基准日），并结合 ROE 中枢判断合理 PB（合理PB ≈ ROE / 要求回报率）。破净既可能是低估也可能是价值陷阱，须结合资产质量核验。

#### 市销率（PS）
```
PS = 股价 / 每股营收
PS = 总市值 / 营业收入
```

**适用场景**：
- 尚未盈利的成长公司
- 互联网公司
- SaaS公司

**估值判断**（阈值去硬编码，对照自身历史）：
| 分位数 | 估值水平 | 适用场景 |
|--------|---------|---------|
| < 20% | 历史低位 | 可重点研究 |
| 20-50% | 偏低 | 结合增长配置 |
| 50-80% | 偏高 | 需增长兑现支撑 |
| > 80% | 历史高位 | 谨慎参与 |

> 校准注释：不套用全市场统一绝对 PS 阈值（如 PS<2 低估值、PS>10 高估值）；PS 分位 = 自身近 10 年月频收盘 PS 分位（标注数据基准日），合理水平取决于营收增速与利润率中枢，须结合同业对比。

#### 企业价值倍数（EV/EBITDA）
```
EV/EBITDA = 企业价值 / EBITDA
EBITDA = 净利润 + 利息 + 税 + 折旧 + 摊销
```

**适用场景**：
- 资本密集型行业
- 并购估值
- 跨行业对比

### 2. 绝对估值法

#### 股息贴现模型（DDM）
```
V = D1/(1+r) + D2/(1+r)² + ... + Dn/(1+r)ⁿ
V：内在价值
D：股息
r：贴现率
```
> yield_basis 口径（S3）：D 采用 DPS，优先券商实际到账/交易所与公司公告口径；默认近 12 个月 DPS 年度化，若单期×4 须显式注明；警惕第三方单期分红失真。DDM 输入的分红预测须标来源或「作者假设」。

**适用场景**：
- 稳定分红的大型蓝筹
- 寿命无限的公司
- 现金流稳定

#### 自由现金流折现（DCF）
```
V = CF1/(1+r) + CF2/(1+r)² + ... + CFn/(1+r)ⁿ
CF：自由现金流
r：加权平均资本成本（WACC）
```

**适用场景**：
- 现金流稳定的成熟公司
- 可预测性强的公司
- 长期投资者

### 3. 特殊估值方法

#### PEG估值
```
PEG = PE / 净利润增长率
```

| PEG值 | 含义 |
|-------|------|
| < 0.5 | 非常便宜 |
| 0.5-1 | 合理偏低 |
| 1-2 | 合理 |
| > 2 | 偏贵 |

> 校准注释：上表为经典经验参考（PEG≈1 为合理锚），非全市场绝对阈值；使用时须标注增速 G 的口径（历史/预测哪一年、来源或「作者假设」），并对照**自身**历史 PEG 区间与同业 PEG 分布校准；亏损或增速为负的公司不适用 PEG。

#### ROE-PB估值
```
合理PB = ROE / 要求的回报率
```

**适用场景**：
- 长期稳定ROE的公司
- 价值投资
- 股东回报视角

## 估值分析框架

### 第一步：确定公司特点
```
分析维度：
- 所处生命周期：初创/成长/成熟/衰退
- 盈利稳定性：稳定/波动/亏损
- 分红能力：有/无
- 行业特点：轻资产/重资产
- 增长预期：高/中/低
```

### 第二步：选择估值方法
```
初创+亏损 → PS、EV/GMV
成长+盈利 → PEG、PS
成熟+稳定 → PE、DCF、DDM
重资产 → PB、EV/EBITDA
金融 → PB
```

### 第三步：收集数据
```
财务数据：
- 营收、净利润
- 净资产
- 现金流
- 分红

市场数据：
- 股价、市值
- 行业平均PE/PB
- 历史分位数
```

### 第四步：计算估值
```
计算各项指标：
- PE = 股价 / EPS
- PB = 股价 / BPS
- PS = 股价 / SPS
- EV/EBITDA = 企业价值 / EBITDA
- PEG = PE / G
```

### 第五步：综合判断
```
判断依据：
- 当前估值在历史中处于什么分位
- 当前估值相对行业平均是高还是低
- 估值与增长是否匹配（PEG）
- 是否有重估催化剂
```

### 估值陷阱检查（必做）
```
作出"低估/可关注"结论前逐项核验：
- 低 PE = 盈利顶部（周期股陷阱）：强周期行业盈利顶部 PE 最低，须用 PB 分位/产品价格分位/产能周期交叉验证
- 回撤大 ≠ 估值低：股价大幅回撤后仍可能高估，以自身历史估值分位为准，不以涨跌幅替代估值判断
- 破净 ≠ 低估：结合资产质量核验（见 PB 校准注释）
- 概念/主题辨真伪：核验相关业务收入占比与商业化进度，警惕主题炒作推高的"合理估值"
- 高股息可持续性：核验分红率与经营现金流对分红的覆盖，警惕一次性特别分红
- 增长质量：核验增长来源、现金流含量与可持续性，警惕低质量增长支撑的高估值
```

## 重要提醒

1. **合规性**：所有分析仅供参考，不构成投资建议
2. **风险提示**：估值只是投资决策的一个维度
3. **动态评估**：估值是动态变化的
4. **综合判断**：结合基本面、行业、竞争等多因素
5. **安全边际**：留足安全边际再买入

## 数据获取与口径

- **获取方式**：优先本地 CLI `bun run main.ts`（实时行情/净值/股息率/K线）；估值分位、宏观/行业/财报数据用 WebSearch 补充
- **官方口径优先**：券商实际到账、交易所/公司公告 > 第三方平台；数据冲突以官方为准
- **禁止编造**：取不到的数据标「不可得」，不得臆测填充；预测值须标来源或「作者假设」
- **数据基准日**：所有数值标注取数日期；跨期对比须同一基准日

数据来源参考：公司财报、交易所公告、行业数据库、宏观经济数据。
