## 二、PE 调节器（每周唯一要查的数）

查询口径：**中证A500（000510）PE-TTM**，中证指数官网 / 理杏仁 / 蛋卷，每周三晚或周四盘前查一次。

**启动条件：PE < 15.5 才开始定投；PE ≥ 15.5 一律不买，只观察。**

| PE-TTM | 当周投入（10 万版） | 逻辑 |
|---|---|---|
| **≥ 15.5 倍** | **¥0，暂停** | 高于历史中位数，不建仓；≥17.5 转入第四节止盈 |
| **14.0 – 15.5 倍** | **¥2,000** | 第一枪区间，标准定投 |
| **12.5 – 14.0 倍** | ¥3,000 | 第二枪区间，加倍 |
| **< 12.5 倍** | ¥4,000 | 第三枪区间，极端低估加速 |

> 阈值与 A500 技能的三枪一致：15.5x / 14.0x / 12.5x。**本策略比技能更严格的一处**：15.5–17.0 的"观望区"也按 0 执行，不再做 1,000 的过渡买入——只在历史中位数以下出手。
>
> **执行细节**：以每周四盘前的 PE 为准，不在盘中判断；PE 在 15.5 附近反复穿越时，按"本周查到的值"执行，不追补、不改单、不因为差 0.05 倍就临时变通。
>
> ⚠️ **代价**：如果 PE 长期在 15.5 以上，预算会长期闲置（可能几个月甚至更久）。这是"不买贵"的必然成本，不是策略失效——**现金也是一种仓位**。
>
> ⚠️ **分位口径警告**：A500 实盘历史仅约 2 年（2024-09 发布），"近 1 年 0.35% 分位"这类说法没有统计意义。**只看绝对 PE 与 PB，不把短窗口分位当锚。**

## 三、为什么锚 PE，不锚点位

1. A500 是**盈利驱动**的宽基：EPS 长期年增约 8–10%，点位会随盈利自然上移，锚点位会逐年失效；锚 PE 能自动适应。
2. 与恒科的分工：恒科利润被外卖/补贴周期污染 → 用 **PB**；A500 行业均衡、盈利相对稳定 → 用 **PE**。
3. **PE 的盲区**：盈利下修时，PE 会"被动变贵"，也可能出现"假便宜"。补丁是每季度核对一次 EPS 一致预期（见第五节）。

| 档位 | 触发 | 动作 |
|---|---|---|
| 偏高 | PE ≥ 17.5 | 减 25% |
| 高位 | PE ≥ 18.5 | 再减 50% |
| 极端 | PE ≥ 19.0 | 清仓 |
| 持有区 | 12.0 – 17.0 | **不动** |

- 减仓后 **30 个交易日内不追**；PE 回落到 15.5 以下，再按第二节重启。
- 不设"累计收益"条件：宽基的估值本身就是卖出理由。

## 五、空方论点与证伪条件（必读，防止只看多）

**空方论点**
- **低 PE ≠ 便宜**：若盈利下修，14.7x 可以变成"贵"；必须核对 EPS 趋势，而不是只看 PE 数字。
- **与现有持仓重叠**：A500 与红利低波、招行、中国移动在银行/能源/消费上高度重合，分散的是个股，不是风险因子。
- **盈利假设偏乐观**：中信证券预计全 A 2026E 利润 +25.7%（2026-10-14），若下修，PE 锚会同步失效。
- **指数历史太短**：2024-09 发布，没有穿越完整牛熊，"历史底部"的参考价值有限。

**证伪条件（触发即重估）**

| 观察指标 | 证伪方向 |
|---|---|
| A500 EPS 一致预期（季度核对） | 下修 → 点位锚同步下移，原"低估"不再成立 |
| PE 与 EPS 联动 | PE 下降但 EPS 同步下滑 = 假便宜 |
| 宏观（地产 / 出口 / 信用） | 恶化到影响指数整体盈利 |
| 相对收益 | 持续大幅跑输沪深300 / 中证500 |

## 六、防心态崩坏条款

- **下跌不停投**：宽基也会出现 20–30% 回撤，跌了是买便宜筹码。
- **不设止损**：指数定投忌割在底部。
- **每月只看一次账户**，其余时间不看。
- **唯一例外**：指数编制规则根本性变化，或个人急需用钱。
- **两个预算池互不挪用**：恒科跌得凶，不代表可以从 A500 的额度里拿钱。
